# ☕ 똑이 카페 랜딩 페이지

브라운 톤의 감성 카페 랜딩 페이지예요. 빌드 도구 없이 HTML, CSS, JavaScript만으로 만든 정적 사이트입니다.
카카오 공식 사이트의 구성(큰 타이포, 패럴랙스, 슬라이더, 스크롤 애니메이션)을 참고했어요.

## 미리보기

`index.html`을 브라우저에서 열면 바로 확인할 수 있어요. 설치나 빌드는 필요 없습니다.

## 폴더 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 구조 (히어로, 스토리, 메뉴, 소개, 오시는 길) |
| `style.css` | 브라운 테마, 라이트/다크 색상 변수, 애니메이션 |
| `script.js` | 스크롤 효과, 다크모드, 슬라이더, 숫자 카운트업 |

## 주요 기능

- 줄별로 올라오며 나타나는 히어로 제목, 김이 올라오는 컵 애니메이션
- 스크롤에 따라 움직이는 패럴랙스 스토리 챕터와 챕터 인디케이터
- 좌우 버튼과 스와이프를 지원하는 메뉴 슬라이더
- 섹션 fade-up, 숫자 카운트업, 상단 스크롤 진행바
- 다크모드 토글 (선택값은 브라우저에 저장, 기본값은 시스템 설정)
- 모바일 반응형, 모션 줄이기 설정 지원, 본문 바로가기 링크

## 수정 방법

- 색상: `style.css` 맨 위 `:root` 변수 (`--brown`, `--accent` 등)를 바꾸세요.
- 메뉴, 가격, 주소, 전화번호: `index.html`의 해당 부분을 고치세요. 지금 들어 있는 값은 예시입니다.
- 이모지로 된 이미지 자리는 실제 사진으로 바꿀 수 있어요.
